# Política de privacidad · Privacy policy

**Job Agent** es una herramienta personal de búsqueda de empleo que funciona en el ordenador de quien la usa.
No es un servicio en la nube y no tiene usuarios externos.

## Datos de Gmail

- Job Agent solo accede al Gmail de la propia persona que lo instala y lo autoriza.
- Lee los correos para detectar los relacionados con la búsqueda de empleo (candidaturas, entrevistas, alertas de
  empleo) y les añade la etiqueta «JOB SEARCH».
- **No envía, no responde, no reenvía, no borra ni archiva correos**, y no crea filtros.
- El permiso de acceso se guarda en el Llavero de macOS del propio ordenador.

## Uso y almacenamiento

- Lo que se extrae de los correos (fecha, empresa, fase de la candidatura) se guarda en archivos locales del
  ordenador de la persona usuaria.
- Para clasificar un correo, su texto se envía a la API de Claude (Anthropic), que lo procesa y no lo usa para
  entrenar modelos.
- Los datos no se venden, no se comparten con terceros y no se usan para publicidad.
- El uso de los datos obtenidos de las API de Google cumple la
  [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
  incluidos los requisitos de uso limitado (*Limited Use*).

## Revocar el acceso

En cualquier momento, desde https://myaccount.google.com/permissions → Job Agent → «Quitar acceso».

## Contacto

A través de este repositorio de GitHub.

---

*English summary:* Job Agent is a personal, local job-search tool. It only accesses the Gmail account of the person
who installs and authorizes it, reads job-related emails and adds a "JOB SEARCH" label. It never sends, replies,
forwards, deletes or archives emails. Data stays on the user's computer, is never sold or shared, and Google user
data is handled in line with the Google API Services User Data Policy, including Limited Use requirements.
